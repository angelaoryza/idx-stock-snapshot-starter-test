Sectors Content Studio · Editor Overhaul Concept · Part 2

The 8 primitives, rendered.

Every card below is the same primitive wearing different data. The tag on each card is the semantic kind the AI and the editor speak. Nothing about the language changes; what changes is that 33 implementations become 8, so grid sizing, selection, callouts and theming get built once each.

P1

BigNumber

One number that owns the moment. Anatomy: label, value, context line, optional callout pill. Whether the number is a yield, an upside or a sector gap is just data.
